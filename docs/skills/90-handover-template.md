# Handover Template

Use this structure after implementing bigger changes.

## 1) Ergebnis
- Was ist jetzt möglich?

## 2) Geänderte Bereiche
- Datenmodell
- Repository/Hook
- UI/Screens
- i18n

## 3) Verifikation
- Welche Checks liefen?
- Ergebnis der Checks

## 4) Risiken
- Offene Kanten oder Annahmen

## 5) Nächste sinnvolle Schritte
1. Optionaler Feinschliff A
2. Optionaler Feinschliff B
